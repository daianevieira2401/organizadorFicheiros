
# Organizador de Ficheiros

## Objetivo
Este programa serve para mostrar os ficheiros de uma pasta, identificar as suas extensões e contar o total de ficheiros.

## Ferramentas utilizadas
- Python
- Spyder
- Git
- Git Bash
- GitHub

## Como executar
1. Abrir o programa organizador.py no Spyder.
2. Selecionar a pasta OrganizadorFicheiros como diretório de trabalho.
3. Carregar em F5 para executar.
4. Ver os resultados na consola.
